# 雪谷旅行报价微信小程序

原生微信小程序，无需安装第三方依赖。支持往返车费、住宿费、雾凇岭、羊草山报价；车费和雾凇岭预设使用用户提供的价格，住宿和羊草山价格手动输入。

## 使用

1. 在微信开发者工具中导入本目录，使用测试号或替换为自己的小程序 AppID。
2. 填写人数、晚数、房间数，选择每项计费方式并填写单价，不需要的项目可关闭。
3. 计算后保存报价或生成报价图片。图片可在预览页面保存或转发。
4. 分享小程序仅分享入口，不携带客户资料或报价内容；给客户发报价请使用报价图片。

报价记录只保存在当前设备，最多30条；清除小程序数据会丢失记录。无后台、无云同步。人数、晚数、房间数为1至9999的整数；单价最多两位小数。未计入的餐费等需另行沟通。

## 验证

运行 `node --test tests/*.test.js` 检查金额计算。微信界面、图片预览和分享需在微信开发者工具及真机验证。本云环境不能运行微信客户端。

正式发布需要你自己的微信小程序 AppID，并在微信开发者工具上传代码、完成平台审核。

## 直通车票价

内置用户提供的16条线路、班次及车程，按每人单程计费。默认哈尔滨中央大街至雪谷80元，雪谷返回哈尔滨80元，合计每人160元。联乘哈尔滨→雪乡→雪谷为每人160元，不另加雪乡→雪谷费用。可选择仅单程，或切换手动车费。报价记录恢复时保留线路选择；旧版记录继续按手动价格计算。票价及班次未经实时查询，请订车时确认。

雾凇岭默认400元/人，上山时间可选7:00、9:00、12:30–13:00或待定，时间会保存并显示在报价图片中。已保存的历史报价保留原价格；新建报价使用新默认价格。

雾凇岭新报价使用固定套票：全票400元，身高1米至不足1.2米半票200元，不足1米免票，恰好1.2米按全票。填写半票和免票人数（均包含在总人数内），其他项目仍按自己的计费方式计算，不自动套用儿童优惠。现金支付，没有现金可找客栈老板换。套票包含项目及接送、免费带玩和拍摄说明来自用户提供的信息。

羊草山新报价：必需穿越门票40元/人，马拉爬犁5公里进山100元/人可独立加选，雪地摩托可选无、半程150元/人、全程登顶300元/人（半程与全程互斥）。默认仅门票，不预选付费项目；选项按全体人数计费，不自动沿用雾凇岭儿童优惠。历史报价保留原计算方式。

羊草山路线图补充：雪谷→茶房→山顶→雪乡约15公里（上山约10、下山约5），9:00–11:00出发；门票不足1.2米免票。摩托全程指茶房至山顶5公里，半程只覆盖此段后2.5公里。去雪乡方向雪飘可选80元/人、滑行约3公里，与返回茶房的天下第一漂不同。雪乡→雪谷60元公路返程通过车费线路计入，羊草山项目不重复收取。免门票优惠仅减门票，不减马爬犁、摩托或雪飘费用。

新增天下第一漂150元/人：从山顶滑向茶房（往雪谷方向），与去雪乡雪飘80元/人二选一或均不选，避免重复收费。旧记录中的80元雪飘选择继续保留。

羊草山新增550元/人套票，和单项组合互斥。550元套票不去雪乡，不需要雪乡回雪谷车票；选择该套票时取消夜间返程加选，并清除返程栏中同一夜间直通车。套票包含马拉爬犁往返、天下第一漂、雪地摩托车；儿童优惠待确认，当前不自动减免。可单独加选夜间雪乡回雪谷60元票（18:00/20:00），若所选直通车线路已包含同一车票，不重复收取。

行程校验：哈尔滨→雪谷去程可选择6:00、8:00、12:30–13:00发车，约5小时。按经营者规则，6:00班车可接当天12:30–13:00雾凇岭，不能选当天7:00或9:00；8:00及午间班车无法接当天雾凇岭。未单独选择游玩日期时视为出行当天；可改为次日或以后，须先选择出行日期。冲突会显示提示并阻止生成报价。此规则仅校验该线路，不代表其他线路已校验。

最终输出新增带日期和时间的行程单，按已填写日期和时间排序，可复制文字或生成长图。哈尔滨6:00出发时显示预计11:00抵达雪谷；选择12:30–13:00雾凇岭后显示该上山时段。支持羊草山日期/时间、返程日期/时间、夜间返程日期/时间。未填写的时间/日期明确标为待定，不自动承诺到达或活动结束时间。

所有直通车去程及返程时间按对应线路班次固定选择，切换线路时清除不匹配的旧时间。夜间回雪谷仅18:00或20:00。哈尔滨经雪乡联乘提供“8:00出发、雪乡18:00转车”及“8:00出发、雪乡20:00转车”两种固定组合。保存或生成报价时也会校验所选班次。

界面采用雪夜深蓝、暖金配色与白色卡片，分别设置车费、住宿、雾凇岭、羊草山模块。套票及路线说明可展开收起；最终行程按时间轴展示，费用清单与总价分区显示。封面使用雪夜配色与雪点装饰。

日期不确定时：新建行程默认按“第一天、第二天、第三天…”安排，出发日期选填。去程视为第一天；雾凇岭、羊草山、返程及夜间返程分别选择行程天数（也可待定）。最终文字及图片按天数和班次排序；填写出发日期后，同时显示对应日历日期。8:00哈尔滨班车不能接第一天雾凇岭，但可安排第二天。清除具体日期保留按天数安排。已有历史报价在恢复时将已知日期换算为行程天数。

直通车列表优先显示哈尔滨→雪谷，其后紧接哈尔滨→雪乡→雪谷联乘。补充车费可添加最多5段额外用车（如去雪乡、雪乡包车回雪谷），按每人单价或整车总价计费；每人计费可填写部分乘客人数，空白默认全体。支持按行程天数及时间生成补充用车安排，报价单逐段列出金额。仅填写尚未计入直通车或夜间返程的费用。

可选新增项目：雪谷内马拉爬犁跑圈默认100元/人、约半小时，雪谷滑雪场默认200元/人。新建报价默认关闭，开启后单独计费，可选择行程天数及开始时间并显示到文字行程、图片。雪谷内跑圈与羊草山马拉爬犁为不同项目，互不抵扣。旧报价没有这些项目时恢复为关闭状态。
